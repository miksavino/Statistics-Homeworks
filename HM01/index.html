1. Introduction: Asymmetric Cryptography & One-Way Trapdoors

In Ethereum and modern public-key cryptography, a private key is fundamentally an integer scalar k chosen uniformly at random. From this secret scalar, the associated public key Q is computed via elliptic-curve scalar point multiplication:

Q = k * G = G + G + ... + G (k times)

, where G is a generator point on the curve.

To explore these group operations, this homework models the relationship using the toy curve y² ≡ x³ + 7 (mod 17).

Apparent Uniformity and Correlation between Input and Output

As k increases b1, consecutive coordinate pairs do not follow a continuous or monotonic trajectory. The coordinates appear to bounce unpredictably across the modular grid, creating an impression of uniform dispersion across the plane. However, the sequence is completely constrained since the generated points never occupy arbitrary positions; they only visit the 17 solutions satisfying the equation y² ≡ x³ + 7 (mod 17).

Furthermore, there is no obvious correlation between the private key k and the public key Q. However, the input and the outpur are still connected by a simple rule: knowing Q = kG determines (k + 1)G = Q + G, meaning that the points are constrained by the geometry of the toy curve rather than being picked at random.

Avalanche-like Behaviour

As seen in the previous analysis, the group addition rule is preserved. Hence, there is no real avalanche effect since the scalar multiplication does not destroy the algebraic structure of the toy curve, unlike what a cryptographic hash function would do. However, by changing only 1 bit in the private key k, the output point can still flip more than 50% of its coordinate bits.

Note on Varying the Base Point G

No experiments were conducted with alternative base points G.

Since G = (1, 5) generates the entire group, iterating k from 1 to 17 visits all 17 points of the curve. Selecting a different valid generatore G' would only change the sequence in which the points are visited, while the set of generated points remains the same.

Hence, all analyzed properties remains unchanged.

Cryptographic implications

Meaningful for a OWF

This operation behaves as a cryptographic one-way function (OWF):

  • Forward direction (computationally efficient): Computing Q = k * G can be solved in polynomial time using scalar multiplication algorithms.
  • Reverse direction (computationally infeasible): Recovering the private key k given only the public point Q and generator G requires solving the Elliptic Curve Discrete Logarithm Problem (ECDLP), for which no polynomial-time classical algorithm is known.

Meaningful for a hash function

Despite the lack of an obvious linear correlation between the input and the output, and despite exhibiting a behaviour similar to an avalanche effect, elliptic curve scalar multiplication does not destroy the underlying algebraic structure.

Furthermore, the output is not statistically independent or uniform: both the coordinate values and individual bits display clear biases.

Hence, while the scattering of points across the plane might give an initial impression of pseudorandomness, the process remains strictly deterministic and algebraically constrained.
